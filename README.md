# 🌐 Orbiting Lines Sphere

> A visually stunning 3D animated sphere with orbiting lines built using **Three.js** ✨  
> Live Demo 🔗: https://orbit-lines-sphere-theunstopabble.netlify.app/

---

## 🚀 Overview

This project features a smooth and mesmerizing **3D orbiting-lines animation** rendered on a digital sphere.  
Think of it as your **visual representation of connectivity, networks, or global motion** — but *stylish*.

✅ Built with modern WebGL using **Three.js**  
✅ Fully interactive and responsive  
✅ Lightweight and smooth animation

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| 🌐 **Three.js** | 3D rendering engine |
| ⚙️ **JavaScript (ES6+)** | Logic & animation control |
| 🎨 **HTML / CSS** | Structure & basic styling |
